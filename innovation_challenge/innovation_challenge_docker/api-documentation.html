SAR MOVE · VDE5050

Vehicle control REST API

Send orders, cancel vehicle actions, load named orders, and inspect the latest vehicle state available from the service.

Open Swagger UI OpenAPI JSON

Quick start

Requests with bodies require Content-Type: application/json.

API base path

/move/vehicleApi

Interactive documentation

Swagger UI provides a try-it-now interface. The machine-readable specification is available at /v3/api-docs.

Operations

Use the host and port of your deployment when calling these endpoints.

POST /move/vehicleApi/callVehicle

Send a vehicle to a map point

Loads the matching node from nodes.json, creates a VDA5050 order, and submits it to the vehicle-control backend.

FieldTypeDescription
vehicleManufacturerstringVDA5050 manufacturer name.
vehicleIdstringVehicle serial number.
mapNamestringTarget map name.
pointNamestringTarget point name.
callbackEndpointstringAccepted by the DTO but not currently used.
actionsstring[]Accepted by the DTO but not currently used.
Request 
{
  "vehicleManufacturer": "SAR",
  "vehicleId": "agv01",
  "mapName": "main-floor",
  "pointName": "station-01"
}
Response 
200 OK
POST /move/vehicleApi/cancel

Cancel an order

Submits a hard-blocking VDA5050 cancelOrder instant action for the vehicle.

FieldTypeDescription
vehicleManufacturerstringVDA5050 manufacturer name.
vehicleIdstringVehicle serial number.
orderIdstringAccepted by the DTO; the current implementation generates the cancel action ID independently.
Request 
{
  "vehicleManufacturer": "SAR",
  "vehicleId": "agv01",
  "orderId": "order-123"
}
Response 
200 OK
POST /move/vehicleApi/namedOrder

Send a named order

Loads order-<orderName>.json, adds vehicle information and a generated order ID, then submits it to the vehicle-control backend.

FieldTypeDescription
vehicleManufacturerstringVDA5050 manufacturer name.
vehicleIdstringVehicle serial number.
orderNamestringName used to load the predefined order file.
Request 
{
  "vehicleManufacturer": "SAR",
  "vehicleId": "agv01",
  "orderName": "go-to-charging-station"
}
Response 
200 OK

POST /move/vehicleApi/statusMultiple

Read multiple vehicle statuses

Filters the latest service state cache and returns matching vehicle statuses.

FieldTypeDescription
vehicleManufacturerstringManufacturer filter.
vehicleIdstringVehicle ID filter.
Request 
{
  "vehicleManufacturer": "SAR",
  "vehicleId": "agv"
}
Response 
{
  "statusList": [
    {
      "vehicleManufacturer": "SAR",
      "vehicleId": "agv01",
      "currentlyMoving": false,
      "paused": false,
      "positionX": 12.5,
      "positionY": 8.25,
      "mapId": "main-floor",
      "charging": false
    }
  ]
}

Runtime notes

Status source

Status endpoints return the latest vehicle state currently available to the service.

Empty state results

If no state is available for a vehicle, the response may contain an empty status object or an empty status list.
